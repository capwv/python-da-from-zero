# Python لتحليل البيانات من الصفر

موقع تعليمي عربي (شرح بالعامية المصرية) لاتعلم Python لتحليل البيانات من الصفر:
14 درس متدرج، 42 سؤال تفاعلي بإجابة فورية، 36 تمرين بحلول نموذجية،
ومعمل Python حقيقي جوه المتصفح (Pyodide / WebAssembly) يشغل الكود على جهازك مباشرة،
ومشروع نهائي لتحليل مبيعات بأرقام متوقعة وفحوصات تحقق.

## المحتوى
- أساسيات Python: متغيرات، نصوص وأرقام، قوائم، قواميس، شروط، حلقات، دوال، ملفات
- NumPy: المصفوفات والفلترة بالأقنعة والإحصائيات
- pandas: DataFrame، فلترة، groupby، دمج، قيم ناقصة
- matplotlib: خطوط وأعمدة وهيستوجرام
- مشروع نهائي: تحليل ملف `sales_data.csv` (بيانات تدريبية مصنوعة، مش معاملات حقيقية)

## التشغيل
الموقع ثابت بالكامل (ملف `index.html` واحد) وبيشتغل على GitHub Pages.
تقدم الدروس بيتحفظ محلياً في المتصفح (localStorage).
المعمل بيحمل Python (Pyodide) ومكتبات pandas/NumPy/matplotlib من CDN عند أول استخدام.

## البيانات
`sales_data.csv` بيانات تدريبية مصنوعة للتعلم (12 طلب، يناير-أبريل 2025).
كل صف طلب واحد فيه منتج واحد؛ الإيراد مش ربح. إجمالي الإيراد 59000.
